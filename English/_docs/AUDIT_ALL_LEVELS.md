## หน้าเรียนว่างเปล่าเกือบทุกวัน — `pwPic is not defined`

**อาการ:** เปิด Day ไหนก็ได้ → เห็นแค่ชื่อเรื่องกับปุ่ม "Let's Start!"
**ไม่มีการ์ดคำศัพท์ ไม่มีจุดบอกขั้นตอน ไม่มีอะไรเลย**

**สาเหตุ:** ตอนฝัง `js/pic.js` เข้า 448 ไฟล์ ผมวาง `<script src="../js/pic.js">`
ไว้ที่**ท้าย `<body>`** แต่โค้ดในหน้าเรียก `pwPic()` ตั้งแต่ตอนโหลด (`checkLock()` → `initContent()`)
ซึ่งรัน**ก่อน** `pic.js` จะถูกโหลด

```
Uncaught ReferenceError: pwPic is not defined
```

พอ throw ตรงนั้น `initContent()` ก็หยุดทั้งก้อน → การ์ด จุด และทุกอย่างที่สร้างต่อจากนั้นไม่เกิดขึ้น

**ขอบเขต:** ทดสอบจริงบนเว็บ Day 1 · 3 · 31 · 121 · 421 — **พังทุกวันที่ทดสอบ ทุก Level**
มีเพียงไฟล์กลุ่ม Day 15–20 ที่รอดเพราะเรียกใน `DOMContentLoaded`
(นี่คือเหตุผลที่ Day 16 แสดงผลปกติ แต่วันอื่นว่าง)

**แก้แล้ว:** ย้าย `<script src="../js/pic.js">` ขึ้นไปใน `<head>` ทั้ง **448 ไฟล์**
ตรวจยืนยัน: pic.js อยู่ใน `<head>` และมาก่อนทุกจุดที่อ้าง `pwPic` — **448/448**

## ทำไมรอบตรวจที่แล้วไม่เจอ

ตอนนั้นผมดัก `window.addEventListener('error')` **หลังหน้าโหลดเสร็จ** — error เกิดไปแล้วตั้งแต่ก่อนหน้านั้น
จึงรายงานว่า `errs: []` ทั้งที่หน้าพังอยู่ และผมดูแค่ว่า `pwPic` เป็น function ไหม (เป็น เพราะโหลดเสร็จแล้ว)
**บทเรียน: ต้องดักerror ตั้งแต่ก่อน script แรกของหน้า ไม่ใช่หลังโหลด**
