# ✅ แก้แล้ว

## 1. `teacher.html` — ให้เซิร์ฟเวอร์เป็นคนตัดสิน

```js
// เดิม
const TEACHER_PASS_LOCAL = 'oxford2026';
if (p === TEACHER_PASS_LOCAL) { ...เข้าได้... }

// ใหม่
let TEACHER_PASS_LOCAL = '';
const r = await jsonpCall({ action:'stats', teacher: p });   // ถาม backend
if (r.status === 'ok') { TEACHER_PASS_LOCAL = p; ...เข้าได้... }
```

**หน้าเว็บไม่รู้รหัสที่ถูกต้องอีกต่อไป** · logout ลืมรหัสด้วย

## 2. `_docs/check_backend.html` — ถามรหัสตอนกดปุ่ม

ไม่เก็บรหัสไว้ในไฟล์ · ขึ้น `prompt()` ตอนกด "ตรวจการเขียน" · เพิ่มคำเตือนบนหน้าว่าเปิดสาธารณะได้

## 3. `dashboard.html` — ตัดทางเข้าผ่าน URL ทิ้ง

- ลบ `ADMIN_SECRET` ออกจากไฟล์
- **`?admin=<รหัส>` เปิด admin ไม่ได้อีกแล้ว**
- เหลือไว้แค่ `?admin=off` สำหรับปิดโหมด (ไม่มีความลับ ไม่เป็นอันตราย)

## 4. `gate-k7m3x9q2p5.html` — เทียบด้วย SHA-256

เก็บแค่ "ลายนิ้วมือ" ของรหัส ตัวรหัสจริงไม่อยู่ในไฟล์

```js
const ADMIN_HASH = '5f7140f0…';          // ย้อนกลับเป็นรหัสไม่ได้
if (await sha256(input) === ADMIN_HASH) { ...เข้าได้... }
```

## ทางแก้จริง: Cloudflare Worker

เช็ก token ที่ระดับ edge **ก่อน** ส่งไฟล์ออกไป → คนไม่จ่ายเงินเปิดไม่ได้เลย
ฟรี 100,000 request/วัน (เหลือเฟือสำหรับ 30–100 คน) · ใช้เวลาทำ ~ครึ่งวัน

**ถ้าจะขายจริง 30 ที่นั่งแรก ควรทำก่อนเปิดขาย** บอกได้เมื่อพร้อม
