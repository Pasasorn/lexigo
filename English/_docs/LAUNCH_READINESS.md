# 🔴 บั๊กที่เจอตอนตรวจครั้งนี้ (แก้แล้วทั้งหมด)

## 1. จ่ายเงินแล้วไม่รู้ว่าใครโอน ← ร้ายแรงที่สุด

**อาการเดิม:** `newPurchase` ส่งแค่ `order_id, pkg, price, type`
คอลัมน์ **name / phone / email** ในชีต `Purchases` **ว่างเปล่า**

**ผลถ้าไม่แก้:** ลูกค้าโอนเงิน → แนบสลิป → ปิดหน้าเว็บก่อนกรอกชื่อ
→ คุณมี **เงินเข้าบัญชี + สลิปในไดรฟ์ แต่ไม่รู้ว่าใคร ติดต่อกลับไม่ได้เลย**
ยิ่งเปิดขาย 30 ที่นั่งพร้อมกัน ยิ่งมีโอกาสเจอ

**แก้แล้ว:**
- เพิ่ม **ชื่อผู้โอน / อีเมล / เบอร์โทร** บนหน้าจ่ายเงิน (บังคับกรอก อยู่**ก่อน**ช่องแนบสลิป)
- `newPurchase` ส่งครบ 3 ค่า
- `Code.gs` เขียนลงคอลัมน์ที่ถูกต้อง (`orderId, name, phone, existingCode, email, ...`)
- ข้อมูลถูก **เติมให้อัตโนมัติ** ในฟอร์มลงทะเบียน — ผู้ปกครองไม่ต้องพิมพ์ซ้ำ

## 2. ทดลองเรียนเก็บ lead ไม่ได้จริง

**อาการเดิม:** ขอชื่อ+อีเมลเพื่อปลดล็อก Day 4–7 แต่โค้ด**ไม่ได้ส่งไป backend**
เก็บแค่ใน localStorage ของเครื่องเด็ก → **คุณไม่ได้ lead สักคน**

**แก้แล้ว:** ส่ง `name` + `email` ไปเก็บในชีต `Purchases` (type = `trial`)
ถ้า backend ล่ม ยังปลดล็อกให้เด็กเหมือนเดิม ไม่กั้น
