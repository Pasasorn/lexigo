## ทำอะไรได้จริง

| กลไก | ผล |
|---|---|
| **ลายน้ำ** อีเมล + รหัสนักเรียน + วันเวลา ทับทั้งหน้าแบบเอียง 24° | ติดไปกับภาพที่แคปทุกภาพ ระบุได้ว่าใครทำหลุด |
| **จอดำตอนสลับแอป / สลับแท็บ / เสียโฟกัส** | ครอบคลุม Win+Shift+S, screen recorder บางตัว, การแชร์หน้าจอบางแบบ |
| **ปุ่ม PrintScreen (Windows)** | ดำจอ 1.2 วิ + ล้างคลิปบอร์ด |
| **บล็อกการพิมพ์** `@media print` + Ctrl+P | กด Ctrl+P → Save as PDF ไม่ได้ |
| **บล็อก Ctrl+S / Ctrl+U / F12 / คลิกขวา / ลากภาพ** | เพิ่มความยุ่งยาก (ไม่ได้กันคนตั้งใจจริง) |
| **สร้างลายน้ำคืนอัตโนมัติทุก 2.5 วิ** | ลบผ่าน DevTools แล้วมันกลับมา |

## ❌ ทำไม่ได้บนเบราว์เซอร์ (พูดตามตรง)

- **แคปหน้าจอบนมือถือ** (iOS/Android) — เว็บไม่มี API ตรวจจับเลย ภาพที่ได้จะ**มีลายน้ำติดไป** แต่ห้ามไม่ได้
- **macOS Cmd+Shift+4** — ไม่ทำให้เบราว์เซอร์เสียโฟกัส จึงไม่ดำจอ
- **ถ่ายรูปจอด้วยมือถืออีกเครื่อง** — ไม่มีเทคโนโลยีใดกันได้ ลายน้ำคือด่านเดียวที่เหลือ
- ทุกอย่างที่รันในเบราว์เซอร์ **ปิด JavaScript ก็หลุดหมด** → ลายน้ำคือการ *ตามรอย* ไม่ใช่การ *ป้องกัน*

👉 **อยากได้ภาพดำจริง อ่านหัวข้อล่างสุด — ต้องห่อเป็นแอป**

# 🎯 ถ้าต้องการ "แคปแล้วได้ภาพดำจริง"

**ต้องห่อเว็บเป็นแอปเท่านั้น** — ไม่มีทางอื่น
เพราะการแคปหน้าจอทำโดย **ระบบปฏิบัติการ** ไม่ใช่เบราว์เซอร์
OS อ่านภาพจากหน่วยความจำจอตรงๆ ไม่เคยบอกหน้าเว็บ และหน้าเว็บก็แก้ภาพที่ถูกเก็บไปแล้วไม่ได้

ภาพจะดำได้ต่อเมื่อ **แอปเจ้าของหน้าต่างสั่ง OS ว่าหน้าต่างนี้ห้ามถูกแคป**:
- Android → `WindowManager.LayoutParams.FLAG_SECURE`
- iOS → เทคนิค secure layer (แอปธนาคารใช้กันทั่วไป)
- Windows/macOS → `setContentProtection` ของ Electron

มาตรฐานเว็บสำหรับเรื่องนี้ **ยังเป็นแค่ข้อเสนอ** ([W3C Manifest Issue #1154](https://github.com/w3c/manifest/issues/1154),
[TPAC 2024 – Capture Prevention](https://www.w3.org/2024/Talks/TPAC/breakouts/capture-prevention.pdf))
ยังไม่มีเบราว์เซอร์ตัวไหนรองรับ

## ✅ เตรียมโค้ดรอไว้แล้ว

`protect.js` มี hook อยู่แล้ว — พอห่อเป็นแอปเมื่อไหร่ จะสั่งบล็อกอัตโนมัติทันที ไม่ต้องแก้เว็บอีก:

```js
window.WTN.disableScreenshot({ ssKey: true });
```

รันบนเบราว์เซอร์ปกติจะข้ามไปเงียบๆ (ไม่มี `window.WTN`) · ลองซ้ำ 20 ครั้ง ทุก 0.5 วิ เผื่อ bridge ของแอปโหลดช้า

**ขั้นตอนถ้าเลือก WebToNative**
1. สมัคร → ใส่ URL `https://peekaword.pages.dev/English/`
2. เปิด AddOn **Disable Screenshot**
3. Build → ได้ไฟล์ `.apk` / `.ipa`
4. ส่งขึ้น Play Store / App Store (ต้องมีบัญชีนักพัฒนา)
5. เว็บไม่ต้องแก้เลย — hook ในโค้ดเรียกให้เอง

## ปรับแต่ง

เปิด `English/js/protect.js`

- **ลายน้ำเข้มไป/จางไป** → `color:rgba(15,23,42,.11)` (ค่ายิ่งมากยิ่งเข้ม แนะนำ .08–.15)
- **ไม่อยากให้ดำจอตอนสลับแท็บ** → ลบ 2 บรรทัดนี้
  ```js
  window.addEventListener('blur', function () { hide(true); });
  document.addEventListener('visibilitychange', function () { hide(document.hidden); });
  ```
- **อยากให้พิมพ์ได้** → ลบ `@media print{html,body{display:none!important}}` ในตัวแปร `css`

## กันจอดำค้าง

มี 3 ชั้น ไม่ให้เด็กติดอยู่กับจอดำจนเรียนต่อไม่ได้:
1. กลับมาที่หน้า → `focus` / `visibilitychange` ปลดเอง
2. **แตะที่จอดำ → หายทันที**
3. ตัวจับเวลาทุก 2.5 วิ: ถ้าหน้าเห็นอยู่จริงและมีโฟกัส → บังคับปลด
