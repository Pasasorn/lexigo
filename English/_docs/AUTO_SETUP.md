# 🧹 ส่วนที่ 1 — ลบแท็บที่ไม่เกี่ยวข้อง

ชีต: https://docs.google.com/spreadsheets/d/1Bw39gtFwaFyoHKerWdxyrUecxZZgB-JFnFx8mMSlnQQ/edit

## ✅ แท็บที่ใช้จริง — ห้ามลบ (7 แท็บ)

| แท็บ | ใช้ทำอะไร |
|---|---|
| **Students** | รายชื่อนักเรียน · รหัส · อีเมล · สถานะ · แพ็กเกจ |
| **Progress** | ความคืบหน้ารายวัน + คะแนนรายทักษะ (`sk_read` `sk_speak` `sk_write`) |
| **Config** | ค่าตั้งระบบ — **สำคัญมาก** |
| **Purchases** | คำสั่งซื้อ · ชื่อ · เบอร์ · อีเมล · สถานะ · สลิป |
| **UsedSlips** | เลขอ้างอิงสลิปที่ใช้ไปแล้ว — **กันคนใช้สลิปเดิมซ้ำ** |
| **QuizAttempts** | สิทธิ์สอบ placement test |
| **QuizScores** | คะแนน quiz แข่งขัน |

> ตรวจจากโค้ดแล้ว **ไม่มีแท็บอื่นที่โค้ดเรียกใช้เลย** — นอกจาก 7 ตัวนี้ลบได้หมด

## 🗑️ ล้างข้อมูล + สร้างแท็บใหม่ให้ถูกต้อง — รันคำสั่งเดียว

ชีตตอนนี้มี 5 แท็บ และ **หัวคอลัมน์เป็นของเวอร์ชันเก่า**
(Progress มีหัวแค่ 4 ช่อง แต่ข้อมูลล้นไป 6 ช่อง และยังไม่มี `sk_read` `sk_speak` `sk_write`)

เพิ่มเครื่องมือไว้ใน `Code.gs` แล้ว 3 ตัว รันจากหน้า Apps Script

### `resetAllSheets()` — ล้างทั้งหมด เริ่มใหม่หมดจด

1. **สำรองก่อน** — ที่ชีต กด **File → Make a copy**
2. **Extensions → Apps Script**
3. ช่อง dropdown ด้านบน (ข้างปุ่ม ▶ Run) เลือก **`resetAllSheets`**
4. กด **▶ Run** → ครั้งแรก Google ขอสิทธิ์ → **Allow**

ได้ผลลัพธ์: ลบทุกแท็บ → สร้าง **7 แท็บใหม่พร้อมหัวคอลัมน์ครบถูกต้อง**
และ **Config ใส่ค่าเริ่มต้นให้ 16 แถวเลย** (เหลือแค่กรอก `slipok_api_key` กับ `payee_last4`)

### `clearTestData()` — ลบเฉพาะข้อมูล เก็บหัวตารางและ Config ไว้

ใช้หลังทดสอบซื้อจริง 1 บาท เพื่อล้างข้อมูลทดสอบ

### `checkSheets()` — ตรวจอย่างเดียว ไม่แก้อะไร

บอกว่าแท็บครบไหม · หัวคอลัมน์เป็นอะไร · มีกี่แถว · **แท็บไหนไม่ได้ใช้ ลบได้**

> ทดสอบ 18 เคสผ่านหมดแล้ว — รวมถึงกรณีชีตมีหัวเก่าแบบตอนนี้

# ⚙️ ส่วนที่ 2 — เปิดตรวจสลิปอัตโนมัติ (SlipOK)

**นี่คือจุดเดียวที่ขวางไม่ให้ระบบเป็น auto อยู่ตอนนี้**
โค้ดเขียนรองรับครบแล้ว แต่ยังไม่มี API key → เลยตกไปโหมด "ส่งให้ครูตรวจ" ทุกครั้ง

## 2.1 สมัคร SlipOK

1. ไปที่ https://slipok.com
2. สมัคร → ยืนยันตัวตน → ผูกบัญชีธนาคารที่ใช้รับเงิน
3. ไปหน้า **API / Developer** → คัดลอก **API Key**

> มีแพ็กเกจฟรีให้ลองก่อน แบบรายเดือนหลักร้อย ถ้ามีลูกค้า 30 คนก็คุ้มแล้ว
> (เทียบกับเวลาที่ต้องมานั่งตรวจสลิปเองทุกวัน)

## 2.2 ใส่ค่าในแท็บ Config

เปิดแท็บ **Config** แล้วเพิ่มแถวเหล่านี้ (คอลัมน์ A = key, B = value)

| key | value | จำเป็น |
|---|---|---|
| `slipok_api_key` | API key จาก SlipOK | 🔴 **ต้องมี** ไม่งั้นไม่เป็น auto |
| `payee_last4` | เลข 4 ตัวท้ายบัญชีที่รับเงิน | 🔴 **ต้องมี** ใช้กันคนโอนเข้าบัญชีอื่น |
| `site_url` | `https://peekaword.pages.dev/English/` | 🔴 ใช้ในลิงก์ที่ส่งทางอีเมล |
| `pts_full_day` | `50` | แต้มเมื่อเรียนครบวัน |

## 2.3 ด่านกันสลิปปลอม 4 ชั้น (โค้ดทำให้แล้ว)

| ชั้น | กันอะไร |
|---|---|
| 1 | **แต่งรูปเอง** → SlipOK อ่าน QR จริงจากธนาคาร ปลอมไม่ได้ |
| 2 | **โอนยอดน้อยกว่าราคา** → เทียบยอดกับราคาแพ็กเกจ |
| 3 | **ใช้สลิปเก่าซ้ำ** → เทียบเลขอ้างอิงใน `UsedSlips` |
| 4 | **โอนเข้าบัญชีอื่น** → เทียบเลขบัญชีปลายทางกับ `payee_last4` |

ถ้าไม่ผ่านชั้นไหน → ตกไปให้คนตรวจ ไม่ได้ปฏิเสธทิ้งทันที (ยกเว้นสลิปซ้ำ = ปฏิเสธเลย)

# 📧 ส่วนที่ 3 — ส่งอีเมลรหัสนักเรียนอัตโนมัติ (ทำให้แล้ว)

**เพิ่มใน `Code.gs` รอบนี้** — พอตรวจสลิปผ่าน ระบบจะส่งอีเมลให้ลูกค้าทันที

เนื้อหาอีเมล: รหัสนักเรียนตัวใหญ่ · ชื่อแพ็กเกจ · ปุ่มเข้าสู่ระบบ · วิธีตั้งรหัสผ่านครั้งแรก

- ใช้ `MailApp` ของ Google — **ฟรี วันละ 100 ฉบับ** (เกินพอ)
- ส่งจากอีเมล `pasasorn@gmail.com` เอง ไม่ต้องตั้งอะไรเพิ่ม
- ถ้าส่งไม่สำเร็จ **ไม่ทำให้การเปิดสิทธิ์ล้มเหลว** — ลูกค้ายังเห็นรหัสบนหน้าจออยู่ดี
- แยกข้อความ 2 แบบ: ซื้อใหม่ / เพิ่ม Level ให้บัญชีเดิม

> ครั้งแรกที่ deploy Google จะขอสิทธิ์ **ส่งอีเมลแทนคุณ** → กด Allow

**ทดสอบแล้ว 13 เคส ผ่านหมด** — อีเมลผิดรูปไม่ส่ง · ไม่มีรหัสไม่ส่ง · ข้อความอัปเกรดต่างจากซื้อใหม่

# 🚀 ส่วนที่ 5 — Deploy

`Code.gs` ตอนนี้เป็น **v7** (เพิ่ม `auto-slip-email`) ไวยากรณ์ผ่านแล้ว 1,712 บรรทัด

1. เปิดชีต → **Extensions → Apps Script**
2. `Ctrl+A` → `Delete` → วาง `Code.gs` ใหม่ → `Ctrl+S`
3. **Deploy → Manage deployments** *(ไม่ใช่ New deployment)*
4. กด **✏️** → ช่อง **Version** เลือก **New version** → **Deploy**
5. กด **Allow** ตอน Google ขอสิทธิ์ส่งอีเมล
6. เปิด `_docs\check_backend.html` → ต้องได้ `"version":"v7"`

แล้ว push เว็บ:

```powershell
cd C:\Users\user\Documents\GitHub\lexigo\English
git add -A
git commit -m "feat: fully automatic purchase flow (slip verify + welcome email)"
git push
```
