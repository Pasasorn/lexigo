# 🎯 ของใหม่ — คะแนนรายทักษะรายคน

กดปุ่ม **📊** ข้างชื่อนักเรียน จะเห็น:

```
🎯 คะแนนรายทักษะ
อ่านออกเสียง   Step 2 · 12 วัน            82%  ████████░░
พูดตามประโยค   Step 3 · 11 วัน            68%  ███████░░░
ฟังแล้วเขียน   Step 4 · 12 วัน            54%  █████░░░░░

✅ ควรส่งเสริม: อ่านออกเสียง (82%)
🔧 ควรฝึกเพิ่ม: ฟังแล้วเขียน (54%)
```

ตามด้วยตารางรายวัน มีคอลัมน์ **อ่าน · พูด · เขียน · แต้ม · วันที่**

**กติกาการอ่านค่า**

- 🟢 ≥80 ทำได้ดี · 🟡 60–79 พอใช้ · 🔴 <60 ควรฝึกเพิ่ม
- **`–` = เด็กข้ามขั้นนั้น ไม่ใช่ทำแล้วได้ 0** — ค่าว่างไม่ถูกนำมาเฉลี่ย
- ถ้าเด็กไม่เคยกดไมค์เลย ช่อง "พูด" จะว่างทั้งคอลัมน์ ไม่ใช่ 0%

## ⚠️ ต้อง Deploy Code.gs ก่อนถึงจะเห็นข้อมูล

คะแนนรายทักษะเริ่มเก็บตั้งแต่ **v6** เท่านั้น

1. Apps Script → วาง `Code.gs` ใหม่ → Ctrl+S
2. **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**
3. ตรวจ: `?action=version` → ต้องได้ `"version":"v6"` และมี `"skill-sync"`

**นักเรียนเก่าจะยังไม่มีข้อมูลย้อนหลัง** — ข้อมูลเริ่มนับจากวันที่เรียนหลัง deploy
หน้าต่างจะขึ้นข้อความบอกตรง ๆ ว่า *"ยังไม่มีคะแนนรายทักษะ"* ไม่แสดงเลข 0 หลอกตา
