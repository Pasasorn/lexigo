      📋 ถ้าไม่ผ่าน ทำยังไง

      1. Google Sheet → Extensions → Apps Script
      2. Ctrl+A → Delete → วาง English/Code.gs ทั้งไฟล์ (1,671 บรรทัด) → Ctrl+S
      3. Deploy → Manage deployments (ไม่ใช่ New deployment)
      4. กด ✏️ ดินสอ → ช่อง Version เลือก New version → Deploy
        ⚠️ จุดที่พลาดบ่อยที่สุด — กด Deploy แล้วแต่ลืมสลับ dropdown เป็น New version
      5. กลับมากดตรวจซ้ำ
