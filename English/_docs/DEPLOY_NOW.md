## ขั้นที่ 1 — เพิ่ม Config 3 บรรทัดในชีต (ทำก่อน)

⚠️ **สำคัญ:** โค้ดจะสร้าง Config อัตโนมัติเฉพาะตอนสร้างชีตครั้งแรกเท่านั้น
ชีตคุณมีอยู่แล้ว → **ต้องพิมพ์เพิ่มเอง ไม่งั้นระบบใหม่ไม่ทำงาน**

เปิด Google Sheet → แท็บ **Config** → เลื่อนลงล่างสุด → พิมพ์เพิ่ม 3 แถว:

| คอลัมน์ A (key) | คอลัมน์ B (value) |
|---|---|
| `payee_last4` | เลข 4 ตัวท้ายบัญชี/พร้อมเพย์ที่รับเงิน เช่น `4821` |
| `site_url` | `https://peekaword.pages.dev/English/` |
| `pts_full_day` | `50` |

**แต่ละอันทำอะไร**

- `payee_last4` — กันคนโอนเข้าบัญชีคนอื่นแล้วส่งสลิปมา (ถ้าเว้นว่าง ระบบข้ามการเช็กข้อนี้)
- `site_url` — ใช้สร้างลิงก์ในเมล "ตั้งรหัสผ่านใหม่"
- `pts_full_day` — คะแนนเต็มต่อวัน (10 เข้าเรียน + 50 ตามผลงาน = 60)

> `pts_per_correct` เดิมไม่ใช้แล้ว ไม่ต้องลบ ปล่อยไว้ได้

## ขั้นที่ 2 — วาง Code.gs

1. Google Sheet → **Extensions → Apps Script**
2. **ลบโค้ดเดิมทั้งหมด** (Ctrl+A → Delete)
3. เปิด `Code.gs` ในโฟลเดอร์โปรเจกต์ → copy ทั้งไฟล์ (1,631 บรรทัด) → วาง
4. **Ctrl+S** บันทึก

## ขั้นที่ 3 — Deploy (จุดที่พลาดกันบ่อย)

**Deploy → Manage deployments** *(ไม่ใช่ New deployment)*

→ กดรูป **✏️ ดินสอ** ที่ deployment เดิม
→ ช่อง **Version** เลือก **New version**
→ กด **Deploy**

> ❌ **ห้ามกด "New deployment"** — URL จะเปลี่ยน แล้วทุกหน้าเว็บจะเรียก API ไม่ได้ทั้งระบบ

URL ต้องเป็นอันเดิม:
```
https://script.google.com/macros/s/AKfycbz8SuCV8PsUkIElDN3rFm9eE1TKm0UOFS5M_u6TrHmxkslAOQuopYmv3IFM0JBoRYq-/exec
```

## ขั้นที่ 4 — ทดสอบทันที (สำคัญที่สุด)

เอา URL ข้างบนไปวางในเบราว์เซอร์ แล้วต่อท้ายด้วย:

**ทดสอบ 1 — รหัสจบวันยาว 8 ตัว (บั๊กที่ใหญ่ที่สุดที่แก้ไป)**
```
?action=save&code=<รหัสนักเรียนของคุณ>&day=22&completion=D22-AB12&score=100
```
- ✅ ต้องได้ `{"status":"ok","day_points":60}`
- ❌ ถ้าได้ `completion code ผิด format` = ยังใช้โค้ดเก่า ให้กลับไปทำขั้นที่ 3 ใหม่

**ทดสอบ 2 — คะแนน 0 ต้องไม่กลายเป็นเต็ม**
```
?action=save&code=<รหัส>&day=23&completion=D23-AB12&score=0
```
- ✅ ต้องได้ `day_points: 10` (ไม่ใช่ 60)

**ทดสอบ 3 — วันนอกช่วงต้องถูกปฏิเสธ**
```
?action=save&code=<รหัส>&day=999&completion=D999-AB12&score=100
```
- ✅ ต้องได้ `เลขวันไม่ถูกต้อง`

> ลบแถวทดสอบออกจากชีต **Progress** เมื่อทดสอบเสร็จ

## ขั้นที่ 5 — SlipOK (ทำทีหลังก็ได้)

ยังไม่ใส่ = ระบบส่งสลิปให้ครูตรวจมือเหมือนเดิม ไม่พัง

1. https://slipok.com → สมัคร → ยืนยันบัญชีที่รับเงิน (**ฟรี 100 สลิป/เดือน**)
2. คัดลอก API key
3. ชีต **Config** → แถว `slipok_api_key` → วางทับ `YOUR_SLIPOK_KEY_HERE`
4. ทดสอบ: สมัครเองที่ `register.html` → อัปสลิปจริง → ต้องได้รหัสภายใน ~5 วินาที

## ✅ เช็กลิสต์หลัง deploy

- [ ] `?action=save&...&day=22&completion=D22-AB12` → `status: ok`

- [ ] กด "ลืมรหัสผ่าน" → ได้เมล → กดลิงก์ → ตั้งใหม่ → เข้าได้
- [ ] เปิด Day 22 ใน **Chrome** บนมือถือ → ไมค์ทำงาน → จบวัน → เช็กชีต Progress ว่ามีแถวใหม่

## 🆘 ถ้าพัง

| อาการ | สาเหตุ | แก้ |
|---|---|---|
| ทุกหน้าเรียก API ไม่ได้ | กด New deployment แทน edit | ลบ deployment ใหม่ → กลับไปใช้อันเดิม → edit → New version |
| `completion code ผิด format` | Code.gs ยังเป็นเวอร์ชันเก่า | วางใหม่ + New version |
| อีเมลรีเซ็ตไม่ถูกส่ง | โควตา MailApp เต็ม (100 ฉบับ/วัน) | รอวันถัดไป หรือใช้ "เข้าด้วยรหัสนักเรียน" แทน |
| ตรวจสลิปขึ้น `manual` ตลอด | ยังไม่ใส่ SlipOK key | ทำขั้นที่ 5 |
| แต้มยังเป็น 510/วัน | ลืมเพิ่ม `pts_full_day` ในชีต | ทำขั้นที่ 1 |
