# 💾 ทำยังไงให้ข้อมูลไม่หาย

## ปัญหาจริงที่ต้องรู้ก่อน

ข้อมูลเดิมอยู่ใน **localStorage** ของเบราว์เซอร์เท่านั้น หายเมื่อ:

| สาเหตุ | เกิดบ่อยแค่ไหน |
|---|---|
| ล้างแคช / ล้างข้อมูลเว็บไซต์ | บ่อย |
| เปลี่ยนเครื่อง / เปลี่ยนเบราว์เซอร์ | บ่อยมาก |
| โหมดไม่ระบุตัวตน (Incognito) | ปิดแท็บ = หายทันที |
| **iPhone/iPad Safari: ไม่เข้าเว็บ 7 วัน** | **อันตรายที่สุด** |

### ⚠️ กฎ 7 วันของ Safari

Apple ลบ localStorage ทิ้งทั้งหมดถ้าไม่มีการ **โต้ตอบกับเว็บนั้น** ภายใน 7 วันที่ใช้ Safari
(นโยบายนี้มีมาตั้งแต่ iOS 13.4 และยังใช้อยู่)

**ตัวจับเวลาจะรีเซ็ตทุกครั้งที่เด็กเข้ามาเรียน** → เรียนสม่ำเสมอก็ไม่มีปัญหา
แต่ถ้าหยุดยาว เช่น ปิดเทอมหรือไปเที่ยว 2 สัปดาห์ กลับมาแล้ว **ข้อมูลหายหมด**

**ข้อยกเว้นสำคัญ:** เว็บที่ **เพิ่มลงหน้าจอโฮม (Add to Home Screen)** ไม่นับเป็น Safari
มีตัวนับของตัวเอง และ Apple ระบุว่าจะไม่ลบข้อมูล → **นี่คือทางแก้ที่ฟรีและได้ผลจริงบน iOS**

# ✅ ที่ทำให้แล้ว

## 1. สำรองบนคลาวด์อัตโนมัติ — ผู้เรียนที่ล็อกอินแล้ว

ทุกครั้งที่กด Finish ระบบส่งขึ้น Google Sheet:

```
&score=72&sk_r=82&sk_s=68&sk_w=54
```

ชีต **Progress** เพิ่ม 3 คอลัมน์: `sk_read` · `sk_speak` · `sk_write`
เล่นซ้ำแล้วทำได้ดีขึ้น → อัปเดตค่าที่ดีที่สุด ไม่ลงโทษการฝึกซ้ำ

**ตอน login ดึงกลับมาทั้งหมด** → เปลี่ยนเครื่อง ล้างแคช เข้าใหม่ก็ครบเหมือนเดิม
(`skillsFor_()` ใน `Code.gs` → `pwMergeCloud()` ใน `login.html`)

> ของเดิมกู้คืนได้อยู่แล้วเฉพาะ **รหัสปลดล็อกรายวัน** (`wla_dN`)
> รอบนี้เพิ่ม **คะแนนรายทักษะ** เข้าไปด้วย

## 2. ขอสิทธิ์ไม่ให้เบราว์เซอร์ล้างทิ้ง

`js/report.js` เรียก `navigator.storage.persist()` อัตโนมัติทุกครั้งที่โหลดหน้า
Chrome / Edge / Android อนุมัติให้เองถ้าผู้ใช้เข้าเว็บสม่ำเสมอ → ข้อมูลไม่โดนล้างอัตโนมัติอีก
(Safari ไม่รองรับ — ต้องใช้วิธี Add to Home Screen แทน)

## 3. สำรองเป็นไฟล์ — ตาข่ายนิรภัยสำหรับคนที่ยังไม่มีบัญชี

ในหน้า `report.html` มีการ์ด **💾 สำรองความคืบหน้า**

- **⬇️ บันทึกเป็นไฟล์** → ได้ `peekaword-progress-2026-08-29.json`
  (เก็บทั้งคะแนนรายทักษะและรหัสปลดล็อกทุกวัน)
- **⬆️ กู้คืนจากไฟล์** → เอาไฟล์กลับมาใส่เครื่องใหม่ได้ทันที

# ⬜ แนะนำให้ทำเพิ่ม

## A. ชวนผู้ใช้ iOS เพิ่มลงหน้าจอโฮม ← คุ้มที่สุดที่ยังไม่ได้ทำ

แก้ปัญหากฎ 7 วันของ Safari ได้ตรงจุด และฟรี

ต้องมี 2 อย่าง:
1. `manifest.json` + ไอคอน 192px / 512px
2. แบนเนอร์เล็ก ๆ ตรวจว่าเป็น iOS Safari แล้วบอกวิธี — *"แตะ ⬆️ แล้วเลือก เพิ่มไปยังหน้าจอโฮม เพื่อไม่ให้ความคืบหน้าหาย"*

บอกได้เลยถ้าจะให้ทำ ใช้เวลาไม่นาน

## B. เตือนก่อนข้อมูลจะหาย

ถ้าเป็น iOS Safari + ไม่ได้เข้ามา 5 วัน → ขึ้นเตือนให้กดสำรองไฟล์หรือสมัครบัญชี

## C. ผูกบัญชีตั้งแต่ทดลอง

แก้ได้ 100% แต่ขัดกับที่เพิ่งเอา email gate ออก — **ไม่แนะนำ**
ทางที่ดีกว่าคือใช้ข้อ A + ปุ่มสำรองไฟล์ที่มีอยู่แล้ว
