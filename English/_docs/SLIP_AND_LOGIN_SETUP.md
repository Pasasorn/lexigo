3. คัดลอก API key
4. เปิด Google Sheet → ชีต **Config** → หาแถว `slipok_api_key` → วาง key ทับ `YOUR_SLIPOK_KEY_HERE`
5. เพิ่มแถวใหม่ (ถ้ายังไม่มี):

| key | value |
|-----|-------|
| `payee_last4` | 4 ตัวท้ายเลขบัญชี/พร้อมเพย์ที่รับเงิน เช่น `4821` |
| `site_url` | `https://peekaword.pages.dev/English/` |

> `payee_last4` คือชั้นกันคนส่งสลิปที่โอนเข้าบัญชีคนอื่น — **ควรใส่**
> ถ้าเว้นว่าง ระบบจะข้ามการเช็กข้อนี้

## 🔎 ตรวจสลิปอัตโนมัติทำงานยังไง

ลูกค้าอัปสลิป → ระบบตรวจ **4 ชั้น** ภายใน ~5 วินาที:

| ชั้น | กันอะไร |
|------|---------|
| 1. อ่าน QR จริงจากธนาคาร | สลิปแต่งรูป / capture ปลอม |
| 2. ยอดเงินตรงราคาแพ็กเกจ | โอนน้อยกว่าที่ต้องจ่าย |
| 3. เลขบัญชีปลายทางตรง `payee_last4` | โอนเข้าบัญชีคนอื่นแล้วส่งสลิปมา |
| 4. `transRef` ไม่ซ้ำใน UsedSlips | เอาสลิปเก่าใช้ซ้ำ / คนละคนส่งสลิปเดียวกัน |

**ผลลัพธ์ 3 แบบ:**

| ผล | เกิดเมื่อ | ระบบทำอะไร |
|----|----------|-----------|
| ✅ `ok` | ผ่านทั้ง 4 ชั้น | **ออกรหัสนักเรียนทันที** ไม่ต้องรอครู |
| ❌ `reject` | ยอดผิด / บัญชีผิด / สลิปซ้ำ | แจ้งเหตุผลให้ลูกค้าแก้ ไม่ให้ผ่าน |
| ⏳ `manual` | API ล่ม / ยังไม่ใส่ key / สลิปเก่า >24 ชม. | ส่งให้ครูตรวจใน `teacher.html` เหมือนเดิม |

> ออกแบบให้ **API ล่มแล้วลูกค้าไม่ตกหล่น** — ตกไปที่การตรวจมือเสมอ ไม่ปฏิเสธเงินลูกค้า

## 🔑 Login ด้วย Email + Password

**หน้า login มี 2 แท็บ:**

- **📧 อีเมล + รหัสผ่าน** ← ทางหลักจากนี้ไป
- **🔢 รหัสนักเรียน** ← ลูกค้าเดิม + คนเข้าครั้งแรก

**Flow ลูกค้าเดิม:** เข้าด้วยรหัส 6 หลัก → ระบบให้ตั้งอีเมล+รหัสผ่าน → ครั้งหน้าใช้อีเมลได้เลย
(มีปุ่ม "ข้ามไปก่อน" ไม่บังคับ)

**ลืมรหัสผ่าน:** กรอกอีเมล → ระบบส่งลิงก์ `reset.html?t=...` ทางเมล อายุ 30 นาที

### ความปลอดภัย

- รหัสผ่าน **hash ด้วย SHA-256 ตั้งแต่ในเบราว์เซอร์** ก่อนส่ง → รหัสจริงไม่เคยวิ่งผ่านเน็ต
  (สำคัญ เพราะ JSONP ส่งผ่าน URL ซึ่งจะถูกบันทึกใน log ของ Google)
- ฝั่ง server hash ซ้ำอีกชั้นพร้อม **salt เฉพาะคน** → ต่อให้ Sheet หลุด เอาไปใช้ login ไม่ได้
- รหัสผิด/ไม่มีอีเมลนั้น → ตอบข้อความเดียวกัน กันคนไล่เดาว่าใครสมัครบ้าง
- ขอ reset → ตอบเหมือนกันเสมอ ไม่บอกว่ามีอีเมลนี้ในระบบมั้ย

### ⚠️ ข้อจำกัดที่ยังเหลือ (ควรรู้)

Login ระบบนี้กันคน**เข้าหน้า dashboard** ได้ แต่ **ไม่ได้กันคนเปิดไฟล์ Day ตรงๆ ทาง URL**
เพราะเว็บเป็น static file ทั้งหมด — ใครรู้ `.../Level1/Day1_LeosBigDay_A1.html` ก็เปิดได้

ถ้าจะกันจริงต้องย้ายไฟล์ Day ไปหลัง **Cloudflare Worker** ที่ตรวจสิทธิ์ก่อนส่งไฟล์
(ทำได้ฟรีใน free tier — แนะนำให้ทำตอนคอนเทนต์ครบ ~365 วัน หรือตอนเริ่มขายจริงจัง)

## 🧪 ทดสอบหลัง deploy

- [ ] สมัครใหม่ + อัปสลิปจริง → ได้รหัสทันที ไม่ต้องรอครู
- [ ] อัปสลิปเดิมซ้ำอีกรอบ → ต้องขึ้น "สลิปนี้ถูกใช้ไปแล้ว"
- [ ] อัปสลิปยอดน้อยกว่าราคา → ต้องขึ้น "ยอดโอนไม่ตรง"
- [ ] เข้าด้วยรหัส 6 หลัก → ตั้งอีเมล+รหัสผ่าน → logout → เข้าด้วยอีเมลได้
- [ ] กด "ลืมรหัสผ่าน" → ได้เมล → กดลิงก์ → ตั้งใหม่ → เข้าได้
- [ ] ใส่รหัสผ่านผิด → ขึ้น "อีเมลหรือรหัสผ่านไม่ถูกต้อง"
- [ ] เช็ก Sheet ชีต `Students` มีคอลัมน์ `pass_hash` / `pass_salt` / `reset_token` เพิ่มมาเอง
